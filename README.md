# finsight-site

Public pages of FinSight, a private expense tracker for iPhone: a placeholder
landing page, the privacy policy (English and Ukrainian) and support.

Published with GitHub Pages from the `main` branch root:
<https://ogphantom.github.io/finsight-site/>. Every tracked file is served as
is (`.nojekyll`), so a push to `main` is a deploy.

- `privacy.html` is the App Store Connect Privacy Policy URL, the URL in the
  app (`AppLinks.privacyPolicy`) and the one given to monobank in the
  provider application. Keep it true to what the app does.
- `support.html` is the App Store Connect Support URL.
